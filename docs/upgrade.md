# VESTIGIA — WEBSITE UPGRADE SPECIFICATION

## Purpose

Transform Vestigia's current website into a **premium, futuristic, conversion-focused B2B tableware platform** that still feels elegant, editorial, tactile, and design-led.

The upgraded site should communicate three things immediately:

1. **We make exceptional tableware.**
2. **We can manufacture at serious B2B scale.**
3. **We make it easy for buyers, retailers, hospitality groups, distributors, architects, and private-label customers to work with us.**

The visual direction should not become a generic "tech startup" website. The futuristic quality should come from **motion, typography, 3D/product visualization, intelligent interactions, spatial layouts, micro-interactions, and strong information hierarchy** while maintaining a premium tableware/editorial aesthetic.

---

# 1. CURRENT WEBSITE — CORE GAPS

## 1.1 Brand positioning gap

The website communicates premium tableware and manufacturing credibility, but the commercial proposition is not immediately structured around the needs of a B2B buyer.

### Problem

A buyer should be able to understand within seconds:

- What Vestigia makes
- Who Vestigia serves
- What scale Vestigia can handle
- What can be customized
- What the minimum order expectations are
- Whether samples are available
- How quickly a buyer can start a conversation
- Why Vestigia is different from other manufacturers

### Upgrade

Create a clear dual-path entry:

**SHOP**

For direct consumers and small orders.

**TRADE / B2B**

For retailers, hospitality, distributors, designers, private-label buyers, and bulk procurement.

The B2B path must be visually dominant enough to generate leads without making the site feel like an industrial catalogue.

# 70. NON-NEGOTIABLE DESIGN PRINCIPLE

Every visual upgrade must answer at least one of these questions:

**Does it make the product more desirable?**

**Does it make the buying decision easier?**

**Does it make Vestigia more credible?**

**Does it make a B2B buyer more likely to start a project?**

If an animation, effect, section, or feature does none of these, remove it.

The goal is not maximum visual complexity.

The goal is **premium clarity + emotional appeal + commercial power**.
